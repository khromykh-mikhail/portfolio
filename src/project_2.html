    • Agenda

    Description

    Une application permettant de gérer un agenda numérique rassemblant un ensemble d’événements.

    Fonctionnalités principales :

    • Modifier le titre et la description de l’agenda
    • Afficher le contenu de l’agenda
    • Ajouter un événement
    • Supprimer un événement
    • Exporter l’agenda sous la forme d’une page HTML
    • Enregistrer l’agenda

    Technologies utilisées :

    • C++
